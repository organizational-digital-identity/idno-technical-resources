# Organizational Digital Identity (IDN°)

**An open project exploring how organizations are represented, perceived and understood online.**

IDN° studies organizational digital identity through concepts, methods, analyses and technical resources. Its approach considers an organization's declared, enacted and calculated identities.

## About this repository

This repository is the technical workspace for the IDN° project. It will progressively host resources that help document and analyse organizational digital identity, including:

- A data model for documenting an IDN° analysis
- Standalone JSON examples
- JSON-LD examples that connect data to a wider graph of information
- Technical documentation and a record of changes

JSON and JSON-LD are presented separately because they serve related but distinct purposes.

## Project status

The repository is at an early stage. The technical resources are being developed and reviewed. Until a resource is explicitly marked as stable, treat it as a draft rather than a finalized specification or adopted standard.
